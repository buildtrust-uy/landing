Qué es BuildTrust

BuildTrust es una plataforma SaaS multi-tenant para la gestión integral de licitaciones en proyectos de construcción de alta gama. Centraliza la documentación técnica, el proceso de cotización con constructoras, y el análisis comparativo de ofertas asistido por inteligencia artificial.

El sistema reemplaza el flujo manual basado en correo electrónico y comparación de planillas impresas por un proceso trazable, auditable y escalable. Su componente diferenciador es un pipeline de IA que normaliza documentos heterogéneos —presupuestos en Excel y PDF de distintas constructoras— y genera una comparación estructurada para la toma de decisión.

React + TypeScript Python + FastAPI PostgreSQL + pgvector AWS Serverless Step Functions

Estado del proyecto

BuildTrust se encuentra actualmente en fase de desarrollo activo. La primera versión cubre el flujo completo de licitación —desde el cierre técnico hasta la adjudicación— para nuestro cliente piloto, UruguayFarms, una empresa que gestiona proyectos de construcción residencial de alta gama para inversores privados internacionales.

La arquitectura está diseñada como SaaS multi-tenant desde su origen, contemplando la incorporación futura de otras empresas del rubro sin rediseño estructural.
